What should the CSV look like?

First row is headers. Recognised columns — title, slug, excerpt, category, banner, bannerAlt, publishAt, tags, keywords, related, draft, body.

Only title, excerpt, category, banner and body are required — the slug is generated from the title and dates can be set below. Separate tags with semicolons: D2C; Creative Testing.

3Set the schedule

Dates already in the file are kept. This fills in anything missing, or overrides everything.

Anything dated in the future stays invisible until that morning — it is stripped out of the build entirely, not just hidden.

5Publish

Everything lands as a single commit, so it either all works or nothing changes. The site rebuilds automatically — roughly 90 seconds.

Everything here is re-checked when the site builds. If something invalid slipped through, the build fails and the live site is left exactly as it was.
